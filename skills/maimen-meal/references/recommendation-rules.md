# 推荐规则（maimen-meal）

本文件是 `scripts/recommend.mjs` 的规则说明。SKILL.md 只保留执行步骤，规则细节在此查阅。

---

## 1. 餐次与用餐目的

两者**独立识别**，不可互相推导（需求说明书 §5）。

### 餐次 mealSlot

| key | 标签 | 时段 | 默认用餐目的 |
| --- | --- | --- | --- |
| `breakfast` | 早餐 | 05:00–09:59 | light-meal |
| `lunch` | 午餐 | 10:00–14:59 | full-meal |
| `snack` | 加餐 | 15:00–16:59 | light-meal |
| `dinner` | 晚餐 | 17:00–21:59 | full-meal |
| `late-night` | 夜宵 | 22:00–04:59 | light-meal |

- 未显式指定时由 `inferSlot()` 按当前时间推断。
- 时段只用于「未指定时的默认值」，**不是硬约束**——用户可以要求在早餐时段吃正餐。

### 用餐目的 mealPurpose

| key | 标签 | 候选要求 |
| --- | --- | --- |
| `full-meal` | 正餐 | 需含主食 |
| `light-meal` | 轻食 | 无强制要求 |
| `drink-only` | 仅饮品 | **必须含饮品** |

「仅咖啡」属于 `drink-only`，候选池只保留带饮品的项。

## 2. 三段式决策流程

```
硬约束过滤 → 软偏好打分 → 最优档抽签
```

### 2.1 硬约束（永不被突破）

按顺序逐项检查，任一不满足即剔除：

| # | 条件 | 说明 |
| --- | --- | --- |
| 1 | `price` 已知且 `≤ 预算` | **价格未知（null）不进入预算内候选**，绝不按 0 处理 |
| 2 | 忌口：`noSpicy` 时剔除辣味 | |
| 3 | 冷热：`drink != any` 时剔除不符项 | `temp === "any"` 视为兼容 |
| 4 | 历史：反馈为 `dislike` 的剔除 | 按餐次范围生效 |
| 5 | 排除集合 `excluded` | 来自 `--no-memory` 之外的历史不喜欢 |
| 6 | 用餐目的：`drink-only` 时剔除无饮品项 | |

**预算为硬上限**，任何活动力度、任何偏好都不放大（需求说明书 §13.2）。

### 2.2 软偏好打分

| 因素 | 分值 |
| --- | --- |
| 历史反馈 `like` | +10 |
| 近期（最近 2 次）已选过 | −3 |
| 等于上一餐次选择 `previous` | −20 |
| 温度契合 `preferredTemp` | +1.5 |

打分只影响排序，**不影响候选集合**。

### 2.3 最优档抽签

- 取分数最高的那一档（可能多个同分）
- 在档内**等概率随机**抽一个
- 随机**只在最优档内**进行，绝不越档

这样既避免每次推荐完全固定，又保证不会为了随机性牺牲偏好。

## 3. 偏好信号来源

偏好信号由 `preference.mjs` 合成，送进 `preferredTemp`。优先级与冲突消解见 `preference.mjs` 注释。

| 来源 | 信号 | 强度 |
| --- | --- | --- |
| 天气（温度） | ≤10°C → hot；≥30°C → cold | 强 |
| 天气（降水） | 雨雪 → hot | 中 |
| 星座（元素） | 火象 → cold；土象/水象 → hot | 弱 |
| 显式 `--drink` | 直接指定 | 最高，覆盖其余 |

冲突时**权重高者主导，弱者转备注**（不静默丢弃）。

---

## 4. 无解处理

无解时返回 `meal: null` + `emptyReason`，且**不回退到全菜单、不放宽预算**。

| 场景 | emptyReason |
| --- | --- |
| 所有候选价格未知 | 所有候选价格未知，无法判定是否在预算内 |
| 预算内无任何候选 | 预算内没有候选（最低 X 元） |
| 仅饮品但无带饮品候选 | 没有符合「仅饮品」的候选 |
| 其他 | 当前条件下没有可行方案 |

---

## 5. 与核价的关系

先按菜单价格及约束初筛，取最多 6 套候选调用 calculate-price。核价后用应付金额重新检查预算，再按偏好排序与抽签。
失败候选保留在 comparison.all，但不进入最终推荐；全部失败返回 failed，全部超预算返回 no-solution，不回退演示。
comparison.best 仅指本次核价且符合约束的最低价；推荐可因口味偏好不同而选择另一套。菜单初筛未覆盖所有优惠组合，不宣称全局最优。
